# Centric OS · Eurest Cafe — demo

A self-contained, offline demonstration of the Centric OS menu-intelligence loop
(Menu Optimizer → Forecasting → Webtrition MyOrders) on a sample site, **Eurest Cafe**.

* `index.html` — the whole demo in one file. Open it in Chrome or Edge, or serve this folder.
* All data is illustrative. Menus, forecasts, suppliers, DINs, prices and account numbers are demo
  values and do not describe any real operation.
* This page is published for a private walkthrough and is not meant to be indexed or redistributed:
  `robots.txt` disallows crawling and the page carries `noindex, nofollow` meta tags. It will be
  taken down after the walkthrough.
